# Домашнее задание по теме Thread Pool

В работе сделано небольшое приложение, которое параллельно отправляет HTTP-запросы к списку публичных API. Для запуска задач используется `ThreadPoolExecutor`, созданный вручную.

## Этап 1. Список адресов

В файле `urls.txt` находится 20 URL. Программа также принимает путь к другому файлу первым аргументом командной строки.

## Этап 2. Настройка пула

Пул настроен следующими параметрами:

- 4 основных потока;
- максимум 8 потоков;
- очередь на 20 задач;
- свободный дополнительный поток завершается через 30 секунд;
- если очередь заполнена, задача выполняется в вызывающем потоке (`CallerRunsPolicy`).

Для потоков используется собственная фабрика с именами `http-worker-1`, `http-worker-2` и так далее. Во время выполнения программа раз в 500 мс выводит количество активных и завершённых задач и размер очереди.

## Этап 3. Выполнение запросов

Каждый URL превращается в отдельную задачу `Callable`. Внутри задачи отправляется GET-запрос, измеряется время ответа и сохраняется статус-код. Для подключения и запроса установлены тайм-ауты, поэтому недоступный API не останавливает всю программу.

## Этап 4. Сбор результатов

Основной поток получает результаты через `Future`. После завершения всех задач выводится таблица с URL, статусом, временем ответа и названием потока. В конце считается количество успешных запросов, ошибок и среднее время ответа.

При проверочном запуске ответили 17 из 20 адресов. Два запроса к GitHub вернули `403`, а один API оказался временно недоступен. Остальные ошибки программа обработала и всё равно вывела итоговую сводку.

## Запуск

Требуется Java 21 или новее.

```bash
javac -d out src/Main.java
java -cp out Main urls.txt
```

Можно передать собственный список адресов:

```bash
java -cp out Main my-urls.txt
```

## Вывод

`ThreadPoolExecutor` позволяет отдельно настроить количество потоков, очередь задач и поведение при перегрузке. Запросы выполняются параллельно, поэтому общее время работы заметно меньше последовательного выполнения.
